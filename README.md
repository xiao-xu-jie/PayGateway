## 项目介绍

小徐支付网关是一款Java开发的支付网关，适用于Developer开发个人应用时快速接入支付功能，支付支持微信、支付宝、QQ等，支持对接官方以及第三方平台（虎皮椒支付、彩虹易支付）；
开箱即用，只需在配置中心配置即可使用，配置一次即可完成多个网站接入支付功能。
